# OpenCV and MediaPipe Snippets (2022–2023)

Short, single-purpose scripts I wrote while learning computer vision — useful as quick references.

| Topic | Scripts |
|---|---|
| Colour | `HSV_ColorPicker.py`, `RGB_or_BGR_ColorPicker.py`, `Color_Tracking.py`, `Two_Color_tracking.py`, `Creating_and_using_Trackbars.py` |
| Contours and ROI | `Countour_Tracing.py`, `countour_tracing_bounding_rectangle.py`, `ROI_using_mouseClick.py`, `parsing_mouseClick.py` |
| Faces | `Frontal_Face_Detection.py`, `Frontal_Face_and_Eye_Detection.py`, `Left_Front_Right_Face_Detection.py`, face-recognition scripts, `faceDetection_Mediapipe.py`, `faceMesh_Mediapipe.py` |
| Hands and body | `mediapipe_handLandmarks.py`, `Left_right_hand_Detection.py`, `mediapipe_fullBody_LandMarks.py`, landmark-parsing classes |
